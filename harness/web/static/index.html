    ONE SERVER. YOUR CONFIGURATION.

    Behind the controls.

    Server-owned credentials. No API keys are requested or stored in this browser.

    Local persistence

    Sessions & queuedata/sessions.sqlite3
    Run logs, screenshots & checkpointsdata/runs/
    Browser cookies & local storagedata/browser-profile/
    Cron & one-time schedulesdata/schedules.json

    Storage paths follow DATA_DIR. Mount this directory as a persistent volume when deploying. Tasks control the browser and workspace on the server running this application.

    Configure once on the server

    Edit the ignored .env file and add ANTHROPIC_API_KEY or DEEPSEEK_API_KEY. Choose LLM_PROVIDER and restart the server. Both keys enable provider fallback.

    Before remote deployment, set GUI_PASSWORD, your allowed hostname, and HTTPS. Use one server worker per data directory. The example configuration stays on localhost.
